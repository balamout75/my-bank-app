🚀 ELK Stack задеплоен!

Проверить поды:
  kubectl get pods -n monitoring | grep -E "elastic|logstash|kibana|filebeat"

Открыть Kibana:
  kubectl port-forward -n monitoring svc/kibana-service 5601:5601
  http://localhost:5601

Открыть Elasticsearch:
  kubectl port-forward -n monitoring svc/elasticsearch-service 9200:9200
  http://localhost:9200/_cluster/health

Первый запуск Kibana:
  1. Перейти в Stack Management → Index Patterns
  2. Создать паттерн: monitoring-logs-*
  3. Time field: @timestamp
  4. Перейти в Discover — логи mybank уже там
